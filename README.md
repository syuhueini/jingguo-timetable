# 桃園市立經國國民中學 115 學年度第 1 學期課表查詢系統

## 功能
- 班級查詢：最多同時選擇 4 個班級，同年級或跨年級皆可複選。
- 教師查詢：先選科目，再指定教師；可跨科複選，最多 10 位不同教師。
- 教師查詢結果：多位教師合併為一張「教師綜合課表」，每格顯示老師、班級與科目。
- 平常不主動顯示「空堂」文字；選擇 2 位以上教師時，可按「查看共同空堂」按鈕，再顯示所有選定教師的共同空堂。
- 課表中的教師姓名可點擊查看該教師課表；班級可點擊查看該班課表，支援教師／班級互相跳轉。
- 保留 115 學年度第 1 學期完整班級課表資料。
