# 經國國中課表網站｜115學年度第1學期

## 本版功能
- 班級查詢：最多同時選擇 4 個班級。
- 教師查詢：最多同時選擇 10 位教師。
- 教師查詢結果為「一張教師綜合課表」，同一節有多位教師上課時，會在同一格逐一顯示「教師姓名＋班級＋科目」。
- 教師查詢結果中的空白格會標示「空堂」。
- 綜合課表下方會自動列出「所有選定教師都沒有課」的共同空堂時段，方便安排辦公室會議或共同討論。
- 科目可複選；選了科目但沒有指定教師時，會納入該科所有教師。若指定教師，則只納入指定教師；可跨科混選。
- GitHub Pages 可直接部署。
